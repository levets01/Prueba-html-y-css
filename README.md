## 📌 Project Description

This project showcases a rock festival website featuring:

- Upcoming events and concerts
- Band information and influences
- Multimedia image gallery
- Responsive navigation menu
- Modern rock-style UI design

## 🚀 Features

- 🎤 Full-screen hero section
- 🎸 Fixed navigation bar
- 📅 Events table with ticket buttons
- 📷 Responsive image grid gallery
- 🧠 About section with band influences
- 🔥 Styled CTA button with hover effects
- 📱 Fully responsive design
- ⚡ Smooth scrolling navigation

---

## 🛠️ Built With

- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (menu toggle)
- Google Fonts: Metal Mania
